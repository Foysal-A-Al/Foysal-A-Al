## MSc Thesis

**Statistically Sound Model Selection: A Comparative Analysis of Machine Learning Classifiers Using Bayesian and Frequentist Methods**

Examined how model selection methodology changes from "Which score is larger?" to "Is the difference statistically credible and practically meaningful?"

- **Benchmark:** 54 datasets, 5 classifiers
- **Evaluation:** Repeated 10×10 cross-validation
- **Frequentist:** NHST with correction
- **Bayesian:** Correlated t-tests, posterior probabilities, ROPE decisions
- **Contribution:** Statistically defensible framework for classifier comparison beyond raw scores

This methodology directly influences how I evaluate clinical, psychiatric, and production AI systems today.
